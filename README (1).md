# Central Park Squirrel Census: Behavior Analysis in Python

Which areas of Central Park have the friendliest squirrels? This project uses Python and pandas to analyze the 2018 Central Park Squirrel Census (3,023 sightings) and find out.

**The answer:** hectare **05E** has the highest share of squirrels that approached people (5 of 15, or 33%), and hectare **07H** had the most approaches overall (6).

## What's here

| File | What it is |
|---|---|
| `Project_1.2.ipynb` | The full analysis: loading and inspecting the data, behavior counts, friendly and scared ratios by hectare, bar charts, and an interactive map |
| `squirrel_map.html` | The interactive map of friendliness by hectare ([open the map](https://kerrygordon777.github.io/central-park-squirrels-python/squirrel_map.html)) |
